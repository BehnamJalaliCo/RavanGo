# IRANYekanXFaNum fonts

The four TTF files in this folder are supplied under a proprietary IRANYekanX / Fontiran license. The license text shipped with the source archive requires an authorized license code and does not clearly grant public source-repository redistribution.

Keep these binaries out of a public repository unless the applicable license explicitly permits it. Authorized developers should place the following files here for a local iOS build:

- `IRANYekanXFaNum-Regular.ttf`
- `IRANYekanXFaNum-Medium.ttf`
- `IRANYekanXFaNum-DemiBold.ttf`
- `IRANYekanXFaNum-Bold.ttf`

RavanGo falls back to the Apple system font if these files are unavailable.
